## Resumo

Quando perguntam por projetos com LangChain, a resposta inclui LangGraph: LangGraph faz parte do ecossistema LangChain (orquestração de agentes em grafo). Usei essas bibliotecas em projetos públicos no GitHub e também em trabalhos freelance e de consultoria cujo código é privado.

## Projetos públicos com LangChain / LangGraph

- **Tiago AI (este Digital Twin)** (https://github.com/Tiagokochem/tiago-ai-twin): agente open source em Python com FastAPI e LangGraph. Fluxo com guarda, roteamento de intenção, RAG híbrido (pgvector + full-text), avaliação de relevância, resposta com citações, voz e WhatsApp.
- **Assistente de agendamento médico** (https://github.com/Tiagokochem/medical-appointment-langgraph): API Node.js (Fastify + TypeScript) com fluxo LangGraph para marcar e cancelar consultas por conversa; estado validado com Zod, modelos via OpenRouter, SQLite.
- **Agente autônomo com LangChain.js e MCP** (https://github.com/Tiagokochem/autonomous-langchain-mcp-filesystem): pipeline LangGraph com LangChain.js, ferramentas via Model Context Protocol (filesystem e MongoDB) e API Fastify; tracing opcional no LangSmith.

## Trabalho privado

Em freelance e consultoria (desde jul/2025) também uso LangChain / LangGraph, RAG com embeddings e bancos vetoriais, e integração de LLMs com CRMs e n8n. Esses clientes são privados, então não publico os nomes dos projetos; o que é público está listado acima e no GitHub.
