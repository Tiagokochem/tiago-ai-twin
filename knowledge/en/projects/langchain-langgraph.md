## Summary

When asked about LangChain projects, the answer includes LangGraph: LangGraph is part of the LangChain ecosystem (graph-based agent orchestration). I have used these libraries in public GitHub projects and in freelance/consulting work whose code is private.

## Public projects with LangChain / LangGraph

- **Tiago AI (this Digital Twin)** (https://github.com/Tiagokochem/tiago-ai-twin): open source Python agent with FastAPI and LangGraph. Flow with guarding, intent routing, hybrid RAG (pgvector + full-text), relevance grading, cited answers, voice and WhatsApp.
- **Medical appointment assistant** (https://github.com/Tiagokochem/medical-appointment-langgraph): Node.js API (Fastify + TypeScript) with a LangGraph flow to book and cancel appointments by conversation; state validated with Zod, models via OpenRouter, SQLite.
- **Autonomous agent with LangChain.js and MCP** (https://github.com/Tiagokochem/autonomous-langchain-mcp-filesystem): LangGraph pipeline with LangChain.js, tools over the Model Context Protocol (filesystem and MongoDB) and a Fastify API; optional LangSmith tracing.

## Private work

In freelance and consulting (since Jul 2025) I also use LangChain / LangGraph, RAG with embeddings and vector databases, and LLM integrations with CRMs and n8n. Those client projects are private, so I do not publish their names; the public ones are listed above and on GitHub.
